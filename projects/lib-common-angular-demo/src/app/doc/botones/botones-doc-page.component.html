Componentes de Botones - Documentación

Botones especializados para CRUD: Agregar, Editar, Eliminar

1. Descripción General

La librería proporciona tres botones especializados para operaciones CRUD:

  • lib-button-add1: Botón para crear nuevos elementos
  • lib-button-action-edit1: Botón para editar elementos existentes
  • lib-button-action-delete1: Botón para eliminar elementos (con confirmación)

2. Botón Agregar (ButtonAdd1)

Botón para crear nuevos elementos:

Propiedades:

@Input disabled boolean Deshabilitar el botón (ej: mientras se carga)
@Input label string Texto del botón (default: "Agregar")
@Output onClick EventEmitter<void> Se dispara al hacer clic

3. Botón Editar (ButtonActionEdit1)

Botón para editar elementos seleccionados:

Propiedades:

@Input item any Elemento a editar (se emite en onClick)
@Input disabled boolean Deshabilitar si no hay item seleccionado
@Input label string Texto del botón (default: "Editar")
@Output onClick EventEmitter<any> Se dispara con el item al hacer clic

4. Botón Eliminar (ButtonActionDelete1)

Botón para eliminar elementos con confirmación:

Propiedades:

@Input item any Elemento a eliminar
@Input disabled boolean Deshabilitar si no hay item seleccionado
@Input label string Texto del botón (default: "Eliminar")
@Output onClick EventEmitter<any> Se dispara al hacer clic (antes de confirmar)
@Output onConfirm EventEmitter<any> Se dispara cuando se confirma la eliminación

7. Patrones y Mejores Prácticas

  • Deshabilitar por contexto: Desactiva Edit y Delete si no hay item seleccionado.
  • Confirmación en Delete: El botón Delete maneja automáticamente el diálogo de confirmación.
  • Mantener coherencia: Usa siempre estos botones en lugar de crear nuevos para CRUD.
  • Estado de carga: Usa el prop disabled mientras se procesan requests.
  • Accesibilidad: Los botones incluyen iconos y estilos de alto contraste.
