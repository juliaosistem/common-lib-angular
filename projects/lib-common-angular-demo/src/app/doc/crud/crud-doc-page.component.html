9. Tips y Buenas Prácticas

  • Modal Obligatorio: Usa CrudDialog1 para manejar la creación/edición de elementos. El CRUD solo maneja la visualización y eventos.
  • Excluir campos innecesarios: Usa excludeFields para no mostrar ID, timestamps, etc.
  • Orden de columnas: Usa fieldOrder para controlar la visualización. El orden en que defines los campos aquí es el que se muestra.
  • Validaciones en el modal: Las validaciones se hacen en CrudDialog1, no en CRUD.
  • Paginación: Activa paginator="true" si tienes muchos registros.
  • Vistas: Alterna entre 'table' y 'grid' según necesites.
